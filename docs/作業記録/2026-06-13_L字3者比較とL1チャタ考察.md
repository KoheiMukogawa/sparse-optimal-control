## 1. 床L字3者比較（実機）

経路 `configs/path_L_turn.yaml`（直線1.5m→左90°→直線1.5m, v_r=0.1, N=15, 10Hz）を
Kanayama / L2 / L1(λ=0.3) で各1本実走。bag: `results/2026-06-13_Lturn_{kanayama,l2,l1}`、
図: `results/2026-06-13_Lturn_plot.png`、まとめ: `results/2026-06-13_Lturn_compare.md`。

### 外部計測（真値）

目標: 1st leg 150cm・90°左折・2nd leg 150cm・最終向き 0°。

| 手法 | 1st leg | コーナー挙動 | 2nd leg | 最終位置 | 最終向き |
|------|--------:|------------|--------:|---------|---------|
| Kanayama | 134cm | 半径~10cmで45°→以後大きい半径（大周り） | 151cm | 中心線の左5cm | 9°左 |

## 2. 原因究明: 実機遅延 × bang-bang（sim で立証）

理想 sim（`test_mpc_sim.py`）では L1 もクリーン（L字 Σ\|u\|≈4.4・反転0）。実機固有要因
＝**求解/通信/速度ループの遅延**（L1 求解 p95 90ms＋…≒2step=200ms）を疑い、
`rover/sim_delay_probe.py` で入力遅延を加えて検証:

| 条件 | L2 Σ\|u\|/反転 | L1 Σ\|u\|/反転 |
|------|---------------:|---------------:|
| 遅延0(理想) | 4.54 / 0 | 4.41 / 0 |
| 遅延1step | 4.52 / 0 | 4.94 / 2 |
| **遅延2step(~200ms)** | 4.52 / **0** | **18.49 / 19** |
| **実機実測** | **4.54 / 0** | **20.71 / 15** |

**遅延2stepで L1 が実機と定量一致**。L2 は全遅延で反転0＝頑健。機序確定: L1 の bang-bang は
遅延下で限界振動化（スライディングモード的チャタ）。L1 は求解時間が L2 の2倍＝自分で遅延を
増やす悪循環。

## 3. 対策: 移動抑制（Δu率ペナルティ, sim検証）

`mpc_core.MPCFollower(move_suppress=w)` を追加（既定0で後方互換）。L1(λ=0.3)を遅延2stepで:

| move_suppress | Σ\|u\| | 反転 | ω0率 |
|--------------:|-------:|-----:|-----:|
| 0.0 | 18.49 | 19 | 56% |
| **2.0** | **5.01** | **1** | 89% |
| （理想・遅延0で 2.0） | 4.43 | 0 | 93%（スパース性維持） |

→ `move_suppress≈2.0` で遅延下チャタ消失かつ理想時のスパース性を保つ。`mpc_follower.py` に
パラメータ実装済み（実機検証は次回）。

## 4. 考察: なぜ Kanayama / L2 / L1 で差が出たか

差は **(i) ωの自由度**（Kanayama は v_r 律速 / MPC は独立）と **(ii) 入力ペナルティの幾何**
（二次=滑らか / L1=疎なbang-off）、そして **(iii) 実機遅延との相互作用** に還元できる。

### 4.1 Kanayama が「大周り」した理由 — ω が v_r に縛られる

制御則 `ω = v_r·(k_y·y_e + k_th·sinθ_e)`（k_y=5, k_th=3, w_r=0）。**ω が v_r(=0.1) 倍**
されるため、コーナーで θ_e≈90°(sin=1)でも
```
ω ≈ 0.1 × (k_th·1) = 0.3 rad/s   ← 実測 max|ω|=0.33 と一致
```
旋回半径 `R = v/ω ≈ 0.33m` → 鋭角を小回りできず外へ膨らむ（大周り）。加えて**予測が無い**
静的フィードバックなので、参照点がコーナーに来て初めて反応＝後手。結果 5cm/9° の残差。
（`v = v_r·cosθ_e + k_x·x_e` ゆえコーナーで cosθ_e→0 となり v も落ちる＝v ディップと整合。）

### 4.2 L2 が最良だった理由 — 予測 × なめらか最適化 × ω自由

- **予測**: 誤差ダイナミクスで N=15(1.5s)先を見てコーナーを予見し旋回を最適化。
- **ωが自由変数（v_rと独立, ≤2.0）** → 左タイヤ中心の小半径ピボットで90°を一発
  （max|ω|=1.67・符号反転0）。
- **二次ペナルティ ‖δu‖²** は補正の限界コストがサイズに比例 → 多数の小補正に分散＝なめらか。
  誤差を終端まで最適に潰す → 終点2cm・傾き0°。
- なめらか＝**位相余裕があり実機遅延に頑健**。

### 4.3 L1 がコーナーでチャタった理由 — bang-off の幾何 × 実機遅延

- **(a) L1ペナルティの幾何**: `‖δu‖₁` は限界コスト一定＋原点に折れ → 「小誤差は δu=0
  （不感帯）、大誤差は一気に最大」の bang-off。直線では操舵不要なので δω=0 を保ち、
  ノイズに不感で蛇行せず最良になれた。
- **(b) コーナー＋w_r=0**: 90°旋回が丸ごと「補正δω」になり L1 が罰する → 飽和バング(ω=2.0)。
  線形ペナルティは「少数の大入力に集約」が最適で、滑らかに分けず一撃で曲がろうとする。
- **(c) 実機遅延が限界振動化**: 飽和バングは行き過ぎる（実測135°＝45°オーバーシュート）。
  遅延で feedback が後手 → 逆向きバング → また行き過ぎ → 限界振動（ジグザグ）。
- **(d) 悪循環**: L1 は求解時間が L2 の約2倍 → 自分で遅延を増やしチャタを助長。

結果、ジグザグの末に終点位置は合うが**最終向き40°破綻**（位置は合っても姿勢追従が失敗）。

### 4.4 なぜ直線と L字でランキングが逆転したか（タスク依存）

| タスク | 理想の入力 | 最良 | 最悪 | 理由 |
|--|--|--|--|--|
| 直線（操舵不要） | ω≈0 を保つ | **L1**(0cm) | Kanayama(14cm) | L1の不感帯＝ノイズに動じず最も真っ直ぐ |
| L字（持続操舵） | 大きく滑らかな旋回 | **L2**(2cm) | L1(向き40°) | L2の滑らか最適化が嵌まる／L1はbangが遅延と組みチャタ |

**同じ「疎・bang」という性質が、無操舵区間では長所・持続操舵では短所**になる。これが逆転の本質。

### 4.5 結論

差の根源は **①ωの自由度（Kanayamaはv_r律速で大周り／MPCは独立で小回り）**・
**②入力ペナルティの幾何（L2=滑らか二次／L1=疎なbang-off）**・
**③実機遅延との相互作用（L1のbangだけ限界振動化）** の3点。

研究的含意: **Maximum Hands-off（L1）の「制御を少数の瞬間に集約」という理想は、
閉ループ＋実機遅延＋大maneuver では限界振動（チャタ）に化ける**。スパース性の真価（直線）と
弱点（コーナー）は同じ原理の表裏。実用には疎性を保ちつつチャタを抑える「移動抑制／遅延補償／
曲率フィードフォワード」が要る（sim検証済み）。L2 は頑健なベースライン。
