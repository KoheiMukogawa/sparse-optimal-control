# 発表スライドのデザイン方針

卒論発表（および以降の研究会）のスライドを作るときの確定ルール。
**根拠**: 久松英治「パワポ外科医が教えるスライドデザインのコツ」
日本小児腎臓病学会雑誌 2024; 37: 111–116.
<https://doi.org/10.3165/jjpn.op.24-015>（CC BY-NC-SA 4.0）

この記事は「フォント・余白・色」の3点に絞ってスライドデザインを論じている。
以下はその3点を本研究（日本語・数値と図が主・聴衆は制御が専門とは限らない）に
読み替えたもの。**原則そのものは出典に従い、具体値だけ本研究に合わせて決めた。**

## 1. 現状の監査 —— `docs/研究会発表_2026-10-22.pptx`（36枚・うち非表示1）

デッキを XML まで開いて実測した。設計は悪くない（テンプレートを使わず自作、
章扉あり、配色も自分で決めている）が、**測ってみると3点とも原則から外れていた**。

| 観点 | 実測値 | 原則との差 |
|---|---|---|
| 欧文フォント | **全 727 run が `latin=Meiryo`**（欧文フォント指定ゼロ） | 「欧文には和文フォントを使わない」に反する。本デッキは `MPC` `L1` `RMSE` `p50 [ms]` `4.5` など**英数字の比率が高い**ので影響が大きい |
| 和文フォント | Meiryo（ゴシック） | ○ 原則どおり |
| コード | MS Gothic 90 run（コード6枚のみ） | ○ **例外として正しい**（日本語コメントと ASCII の桁を揃えるには和文等幅が要る） |
| 文字サイズ | サイズ指定のある 822 run のうち **94 % が 18 pt 未満**。最頻は 12.5 pt（319 run＝全体の 39 %） | 13.33×7.5 in のスライドで 12.5 pt は「読ませる」サイズ。「見せる資料」ではない |
| 情報量 | 総 12,936 字 / 36 枚 = **平均 359 字・中央値 368 字**（最大 851 字）。150 字を超えるのが **32 枚** | 「文字だらけのスライド」。記事の結論が名指しで批判している状態 |
| 色数 | **23 色**。うち近似重複が6組（墨3種 `23292F`/`222A30`/`202A33`、灰2種、オフ白5種、淡青2種、緑2種、赤系2種）＝統合すれば 13 色 | 「背景色・文字の基本色・メインの色・強調の色の4色」に対して多い。しかも重複分は**見た目の効果がゼロ**で不統一なだけ |
| 配色の一貫性 | **解説図は L2=ティール `#1F6F8B` / L1=橙 `#E07A3F`、結果図は L2=青 `#0072B2` / L1=朱 `#D55E00`** | **同じ手法が前半と後半で違う色**。聴衆は色で手法を追うので、ここが最大の問題 |
| ページ番号 | 32枚に**手打ちのテキストで**記入 | 記事は「入れない」を推奨。入れるとしても手打ちは1枚挿入するたび全手直しになる |
| 余白 | 1〜32枚目は左右の本文余白が狭く、33〜36枚目だけ左 0.72 in・上 0.52 in。**23枚目は図が右端から 0.23 in はみ出している** | 10/15 に追加した4枚だけレイアウトが別系統 |
| 図形 | 295個。うち**色のついた面が132個**（角丸カード32・擬似シャドウ25・飾りバー42・色帯21・タブ3・シェブロン7・▼2） | 角丸カード＋擬似シャドウ＋飾りバーは Web/ビジネス資料の語彙。研究発表には出てこない |
| 本文の組み方 | 295個のうち163個は**塗りも枠線もない素のテキストボックス**。見出しも色帯ではなく文字 | ○ 原則どおり。本文を箱に入れていないのは良い |
| テンプレート | PowerPoint 既定テンプレート不使用・自作 | ○ 原則どおり（記事の図4の問題を回避できている） |

> 注: この環境には LibreOffice も poppler も無いため、**描画しての目視確認はできていない。**
> 上はすべて OOXML の実測値。見た目の最終判断は PowerPoint で開いて行うこと。

## 2. 確定ルール

### フォント

| 用途 | 和文 | 欧文・数字 | サイズ |
|---|---|---|---|
| 本文 | Meiryo | **Segoe UI** | 20 pt 既定・**18 pt 下限** |
| 見出し | Meiryo 太字 | Segoe UI Semibold | 26〜28 pt |
| 表の中身 | Meiryo | Segoe UI | 16 pt 下限 |
| コード | **MS Gothic（欧文も MS Gothic）** | 同左 | 14 pt 下限・1枚 12 行以内 |

- 和文はゴシック（スライドは「読ませる」でなく「見せる」＝視認性優先）。
  **卒論本文が明朝なのは正しい**——長文は可読性優先なので役割が違う。
- 欧文・和文中の英数字は必ず欧文フォント。Meiryo＋Segoe UI は字面の相性がよく、
  Windows 標準なので文字化けせず、太字にしても潰れない（記事の推奨そのまま）。
- **コードだけは和文フォントを欧文にも使う。** 原則の例外だが、
  日本語コメントと ASCII が混ざる行で桁を揃えるには等幅の和文フォントが要る。

### 色（4色＋無彩色）

**有彩色はデータ（手法・条件）だけに使う。構造（帯・罫線・扉・箱）は無彩色にする。**
こうすると「色がついている＝手法を指している」という規則が1つで済み、色数も減る。

| 役割 | 色 | 用途 |
|---|---|---|
| 背景 | `#FFFFFF` | 図が白背景（matplotlib 既定）なので白で揃え、「貼り付け感」を消す |
| 文字の基本色 | `#23292F` | 本文・見出し |
| 補助（無彩色） | `#4F5A63` / 下地 `#F6F8F9` | 注記・罫線・箱の下地。色数を増やさずに階層を作る（記事 図10b の「灰色を使う」） |
| データ4色 | `#E69F00` Kanayama ／ `#0072B2` L2-MPC ／ `#D55E00` L1（素） ／ `#009E73` L1＋移動抑制 | `rover/fig_style.py` の `COLOR` と**同一**。卒論の図・表と完全に一致させる |

- **強調の色は `#D55E00`（問題・チャタリング）と `#009E73`（対策後）の2色だけ**。
  これは上のデータ色と同じ意味なので、本文の語を強調しても意味が衝突しない。
- 墨3種・灰2種・オフ白2種・淡青2種・緑2種の重複は**片方に寄せて消す**。
- ティール `#1F6F8B` と橙 `#E07A3F`（現デッキの地の色）は**廃止**。
  Okabe-Ito 4色に寄せる理由は ①卒論の図と同じになる ②色覚多様性への配慮が済んでいる
  （`fig_style.py` に検証記録あり）③解説図と結果図で同じ手法が同じ色になる。
- 白背景には白文字を置かない／背景が暗い帯の上は白文字。明度でコントラストを取る
  （色相を変えるだけではハレーションを起こす）。

### 余白とノイズ

- 本文領域は**左右 0.7 in・上下 0.4 in を空ける**。見出し帯だけ全幅可。
  全スライドで同じ値にする（現状の 1〜32 / 33〜36 の二系統を1つにする）。
- **ページ番号は入れない。** 質疑で参照したいなら、手打ちではなく
  スライド番号フィールド（挿入→スライド番号）にして自動更新させる。
- 日付・所属ロゴ・発表会名は**タイトルスライドだけ**。
- 「論文解説 01」のような章ラベルは**残してよい**（現在地を示す情報であって装飾ではない）。
- 余白を埋めたくなったら、埋めずに**1枚割る**。

### 図形（装飾を足さない）

スライドに出てよい要素は**図・表・数式・結論1行・細い罫線**だけ。これ以外が出ると、
中身ではなく体裁の資料に見える。具体的に**使わない**ものは次。

- **角丸**（`roundRect`）。角は直角にする
- **擬似ドロップシャドウ**（カードの背面に一回り大きい淡色の面を敷く）
- **飾りバー**（情報を持たない短い色の帯）。見出しの下に引くなら
  **幅は見出しと同じ・太さ 0.75 pt・無彩色の罫線1本**にする
- **タブ**（上角だけ丸い見出し形）・**色帯**（全面の色塗り。章扉も白地でよい）
- **枠線の色分け**。枠線を残すなら薄灰1色に統一する
- **意味のない色の箱**。囲みたくなったら、囲まずに余白と太字で区切る

逆に**残してよい**もの:

- **矢印（シェブロン・▼）**。構成図やフローの流れを運んでいる＝装飾ではない
- **表のセル塗り**。データの読み取りを助ける。ただし見出し行は無彩色にする
- 細い罫線1本

### 1枚の情報量

- **本文 150 字以内**（現状の平均 359 字の半分以下）。超えたら分割する。
- 1枚＝1メッセージ。見出しは体言止めでなく「何が言えるか」を書く
  （例: ×「計算負荷」→ ○「求解は 0.1 秒以内に収まっている」）。
- 箇条書きは3項目まで。表は 4 行 × 4 列まで。

### 図とスライドの一体化

- 図の背景とスライドの背景を一致させる（どちらも白）。白縁や枠線を付けない。
- **図の中にタイトルを焼き込まない。** スライド側の見出しと二重になる。
  （卒論 LaTeX でも同じ問題が出ている → `docs/handoff.md` の「図の二重タイトル」）
- 図中の文字は 14 pt 相当以上（`fig_style.setup()` の既定で足りているか毎回確認）。

## 3. 次の卒論発表スライドへの適用手順

土台は `docs/研究会発表_2026-10-22.pptx`。上から順に、機械でできるものから。

1. **フォントと装飾の一括処理**（機械）: `python3 docs/restyle_pptx.py 入力.pptx --plain`
   で、`latin=Meiryo` → `Segoe UI`・近似重複色の統合・テーマフォント（現在 Calibri）の修正に加え、
   **装飾を剥がす**（角丸→直角、擬似シャドウ・色帯・タブの削除、飾りバー→0.75pt 罫線、
   枠線の除去、表の見出し行を無彩色に、文字色を図の配色へ）。`--plain` 無しならフォントと色だけ。
   元ファイルは触らず別名出力する。10/22 のデッキに当てた結果:

   | | 置換・削除 |
   |---|---|
   | 欧文フォント → Segoe UI | 746 箇所 |
   | 近似重複色の統合 | 302 箇所 |
   | 装飾の削除 | 58 個（図形 295→237） |
   | 飾りバー → 罫線 | 37 本 |
   | 角丸 → 直角 | 30 個 |
   | 塗り・枠線の除去 | 42 箇所 |
   | 文字色の修正 | 100 箇所 |
   | 表の見出しを無彩色に | 20 セル |

   残った色は **墨 `#23292F` / 補助 `#4F5A63` / 灰 `#6B7680` / 下地 `#F6F8F9`・`#E4EFF3` /
   強調 `#D55E00`・`#009E73`**＝無彩色＋図と同じ2色。出力済み:
   `docs/研究会発表_2026-10-22_plain.pptx`（**PowerPoint で開いて目視確認すること**）。
2. **解説図の配色を直す**（コード・要 uv）: `docs/make_paper_figs.py` の
   `TEAL`/`ORANGE` を `rover/fig_style.py` の `COLOR["l2"]`/`COLOR["l1"]` に置き換え、
   `docs/論文解説_figs/*.png` を再生成してスライドに貼り直す。
   **ここを直すと前半と後半で手法の色が揃う。優先度は最も高い。**
3. **文字を削る**（手作業）: 1枚 150 字まで。読み上げる文はノートへ移す。
   削った結果サイズを 20 pt に上げられるか毎枚確認する。
4. **ページ番号を消す**（手作業・32箇所）。
5. **余白を揃える**（手作業）: 33〜36枚目を他に合わせ、23枚目のはみ出しを直す。
6. PowerPoint で開いて**全枚を目視**（WSL 側では描画できない）。
