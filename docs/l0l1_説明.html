1ひとつのグラフから、ふたつの数が取れる

ロボットが経路を走るあいだ、操舵をどう使ったかを1本のグラフに描く。横軸が時間、縦軸が操舵の大きさである。棒が立っていればその瞬間ハンドルを切っており、棒がなければ手を放している。

この同じ1本のグラフから、性格のまったく違う2つの数が取れる。この区別がつけば、以下の議論の大半は済んだことになる。

測り方値数え方
L0 ＝ 動かしていた時間4棒が立っている本数を数えるだけ。高さは一切見ない。高さ 0.6 の棒も高さ 1 の棒も、同じ「1本」と数える
L1 ＝ 動かした量3.4棒の高さを全部足す（1 + 0.6 + 0.8 + 1）。本数は見ない。グラフと横軸ではさまれた面積に当たる

卒論の式は、これをそのまま言っている

‖u‖₀ = L(supp u)
supp u（台）は「u がゼロでない時刻を集めたもの」、L は「その長さ」。つなげて読めばゼロでない時間の長さ、すなわち上の「本数」である。
‖u‖₁ = ∫|u(t)| dt
∫ は足し算、|u| は向きを無視した大きさ。つなげて読めば大きさを全部足した値、すなわち上の「高さの合計」＝面積である。

本来小さくしたいのは L0 である。L0 が小さい＝操舵している時間が短い＝手を放している時間が長い。これが最大ハンズオフ制御の目標そのものである。

ところが L0 は数える量なので、どの瞬間を使いどの瞬間を捨てるかという組み合わせを総当たりするしかなく、現実的な時間では解けない（50 ステップなら 2 の 50 乗通り）。いっぽう L1 は面積なので、凸最適化のソルバが確実に解く。

したがって L1 で代用したい。問題は代用して本当に差し支えないのかの一点であり、以下はその検討である。

2ルールはひとつだけ ── 全開を超えられない

卒論の式 (2.8)(2.13) に ‖u‖∞ ≤ 1 という制約が入っている。読み方は「どの瞬間の操舵も大きさが 1 を超えない」。1 は全開のことで、実際の上限 u_max で割って単位をそろえてある。

見かけは地味な制約だが、以下の議論はすべてこの「上限 1」に乗っている。上限がなければ L1 と L0 のあいだに関係はつかない。

3L1 は L0 より大きくならない

5 ステップの例を2つ作り、両方の数を出す。

理由は棒1本ずつ見れば分かる。

棒の高さL0 への寄与（本数）L1 への寄与（高さ）大小
000同じ
1（全開）11同じ
0.510.5L1 が小さい
0.110.1L1 がずっと小さい

棒1本について必ず「L1 の寄与 ≤ L0 の寄与」になる。棒がゼロでなければ L0 には必ず 1 が入るのに、L1 に入るのは高さの分（上限 1）だけだからである。全部足しても向きは変わらないので、どんなグラフでも次が成り立つ。

‖u‖₁ ≤ ‖u‖₀動かした量は、動かした時間を超えない（上限 1 による）

すなわち L1 は L0 を必ず下から見積もる数である。

そして表からもう一点読める。等号になるのは棒の高さが 0 か 1 しかないときに限る。中途半端な高さの棒が1本でも混じれば、そこで L1 が L0 より小さくなる。この「ゼロか全開だけ」の形を bang-off-bang と呼ぶ（bang = 振り切る、off = 止める）。卒論 §2.5 の式 (2.9) はこの形を指している。

4下から見積もる数を最小にして、なぜ本物が最小になるのか

ここが要点なので、いったんロボットを離れる。

クラスでいちばん背が低い人を知りたい（＝ L0 を最小にしたい）。ところが身長は直接測れず、手元には必ず実際より小さい値が出る壊れた測定器しかない（＝ L1 ≤ L0）。これでは通常、最も背が低い人は決められない。測定値が小さい人について、本当に小さいのか測定器が特にサボったのか区別できないからである。

ところが次の2つがそろうと決まる。

A さんの測定値が最小で、しかも A さんについてだけ測定器が正しかったとする。すると誰を持ってきても次が成り立つ。

A の真の身長 ＝ A の測定値A では測定器が正しかった（仮定）
　　　　　　　 ≤ その人の測定値A の測定値が全員のなかで最小だから
　　　　　　　 ≤ その人の真の身長測定器は誰に対しても小さめに出るから
→ A の真の身長 ≤ 誰の真の身長。すなわち A さんが真にいちばん背が低い。

ここで重要なのは、測定器が他の人に対して正しいかどうかを一切使っていない点である。A さん1人について一致していれば足りる。

ロボットの話に戻す

身長の話制御の話
知りたい真の身長L0（手を放していない時間）＝本来最小化したい量
測れる測定値L1（動かした量）＝実際に解ける量
測定器は必ず小さめに出る‖u‖₁ ≤ ‖u‖₀（第3節の不等式）
A では測定器が正しいその解が bang-off-bang（高さが 0 か全開だけ）

L1 を最小にする解を u* と書く。もし u* が bang-off-bang であれば、どんな入力 u に対しても次が成り立つ。

‖u*‖₀ ＝ ‖u*‖₁u* は 0 か全開しかない ＝ 等号の条件を満たす
　　　　 ≤ ‖u‖₁u* は L1 を最小にした解だから
　　　　 ≤ ‖u‖₀第3節の不等式（任意の u で成立）
→ ‖u*‖₀ ≤ ‖u‖₀。L1 を解いて得た解が、L0 の解でもあることになる。

これが卒論 §2.5 で参考文献 [6] として引いている主張の中身である。現在は引用のみで済ませているが、この3行で説明できる。定理1（可到達性＋A の正則性）を経由しないため、A が冪零な本研究の系でも使える経路である。

そのかわり、あらかじめ保証するのではなく解いてから解の形を見て判定する手順になる。

この3行はまるごと「もし u* が bang-off-bang なら」という仮定の上に乗っており、仮定が外れれば1行目の等号が崩れて議論全体が止まる。したがって次に確かめるべきは、実際にそうなっていたのかである。

5実測 ── 厳密な 3 値ではなかった

2026-11-26 の訂正 卒論 chapter2.md:294-295 は §2.6 の解について「δω が {−1, 0, +1} の3値のみをとる bang-off-bang 構造」と書いているが、実測すると厳密には3値ではない（results/2026-11-26_l0_support/notes.md 所見3）。第4節の前提は満たされていない。

§2.6 の数値実験（h = 0.1 s、V = 1.0 m/s、50 ステップ、初期誤差 2.0 m・1.0 m・30°）の解を実際に数えると、次のようになっている。

さらに、並進補正 δv は全 50 ステップが非ゼロ（一律 −0.4）で、こちらは bang-off-bang から程遠い。

第3節の等号条件は「高さが 0 か 1 しかない」であった。中間値が2個混じるため等号は成り立たず、第4節の1行目が書けない。すなわち文献 [6] の結論の前提が、この事例では満たされていない。身長の例えで言えば、「A さんについてだけは測定器が正しかった」という肝心の確認が取れなかったことになる。

6総当たりで L0 の答えを直接数えた

前提が満たせないなら、推論に頼らず総当たりで L0 の解そのものを求めればよい。これが 2026-11-26 に実施した S8（rover/l0_bruteforce.py）である。

手順は素朴である。「どのステップを使うか」の組み合わせを、使うステップ数 k の小さい順に全部試し、目標に到達できる最小の k を見つける。そのうえでその最小の支持だけに限定して L1 を解き直し、制限なしで解いたときと同じ L1 最適値に届くかを見る。届けば「L1 の最適解のなかに L0 最適なものが存在する」と言える。

総当たりできた6事例すべてでこれが成り立った。

初期誤差 x₀nL1 解の活性数L0 最小最小支持の数L0 最小の支持上に L1 最適解
(0.05, 0.05, 5°)6651はい
(0.05, 0.05, 5°)101038はい
(0.10, 0.10, 10°)101062はい
(0.00, 0.20, 20°)1511117はい（活性数も一致）
(0.10, 0.20, 15°)20207281はい
(0.00, 0.10, 0°)202255はい（活性数も一致）
(2.0, 1.0, 30°)5050総当たり不能—下界 20（活性 50 は下界の 2.5 倍）

最後の行が §2.6 の事例で、2 の 50 乗通りあるため総当たりできない。ただし活性ステップ数の厳密な下界は ⌈|x₀ˣ|/(h·u_max)⌉ = 20 と計算できる（δv は x 方向にしか効かず、合計が x₀ˣ に等しくなければならないため）。

これは主張が弱くなる訂正ではない。「定理の前提に合わせて主張を限定する」から「自分の系で数値的に検証した」へ、根拠が推論から実証に変わっている。しかも bang-off-bang という前提に依存しないため、文献 [6] 経由の論拠より強い。

7L1 を解いても疎な解が出るとは限らない

図6 の①で、ソルバが 3 ステップで足りるところを 10 ステップ全部使っていた。これは偶然ではなく、L1 最小化の性質である。

L1 問題は、最適値が一意でも最適解は一意ではない。第1節の例A と例B を思い出すと、「高さ 1 を 2 本」と「高さ 0.5 を 4 本」は L1 がどちらも 2 で区別がつかなかった。L1 から見て同点の解が複数あるとき、どれが返るかはソルバ任せになる。§2.6 の δv で起きているのはこれである。

総当たりの6事例でも、ソルバの活性数が L0 最小を上回る例が 4/6 あった（n = 20 の事例では 20 対 7）。すなわち「L1 を解けば疎な解が出る」は自動ではない。

MPC では毎周期解き直して先頭の入力しか使わないため実害は小さいが、オープンループで全区間を一度に解く §2.6 では正面から効く。口頭試問で図2.5 の δv を指された場合、この説明が必要になる。

8なぜ L2 ではなく L1 なのか

L1 が L0 を下から見積もるのなら、下から見積もる関数は他にもある。実際あるが、L1 には特別な地位がある。横軸に操舵の大きさ、縦軸に「そのとき払う罰金」をとって3つを重ねる。

罰金原点のまわりの形結果
L0ゼロなら 0、少しでも動かせば即 1（段差）本来課したい罰金だが、段差のため最適化にかけられない
L1 ＝ |x|角がある。ゼロから離れた瞬間に傾き 1 で立ち上がる「少しだけ動かす」が高くつくので、最適解はきっぱりゼロを選ぶ
L2 ＝ x²平ら。0.1 動かしても罰金は 0.01「少しだけ動かす」がほぼ無料。ゼロにならず常に動き続ける（L2-MPC が常時操舵になる理由）

すなわち L1 は L0 の段差を下から支えられる関数のうち最も階段に近いものである。任意に選んだ代用品ではなく、「解ける形のなかで L0 にいちばん近いもの」として選ばれている。これが「なぜ L1 なのか」の答えである。

角があることの実際の効き方 ── 不感帯

原点の角は、コントローラの振る舞いとしては不感帯として現れる。誤差が小さいうちは補正をまったく打たず、ある大きさを超えたところで打ち始める。

9u ではなく補正 δu に掛ける

最後に、原理論から本研究への変更点をこの図の上で確認する。

速度そのもの u を疎にすると、ゼロである時間が最大化されるためロボットが走行そのものを止めてしまい、経路追従にならない。そこで疎にする対象を、参照速度からの補正 δu に変える。

10主張すること、しないこと

以上を踏まえると、言える範囲は次のように整理される。

論拠の経路成否理由
定理1（文献 [3]）で一致を言う使えない十分条件は可到達性 ＋ A の正則性。本研究の A は冪零（A² = O・det A = 0・rank A = 1）
単入力に縮約して定理1 を使う使えないδω のみに縮約すると可到達性まで失う（rank 2 < 3）
文献 [6]（bang-off-bang 経由）前提を満たさない§2.6 の解は 9/11 が飽和値だが 2 成分が中間値（第5節）
S8: L0 総当たりとの直接照合使える検証した全6事例で「L0 最小の支持上に L1 最適解が存在」（第6節）
言ってはいけないこと
  • 「定理1 により一致する」── 十分条件を満たしていない。
  • 「L1 なら必ず L0 最適」「本研究の MPC 解は必ず bang-off-bang」── 初期値依存であり、実際 §2.6 の解は厳密な3値ではない。
  • 「L0 最小化は NP 困難」── 参考文献 [3] の本文にこの語は無い（2026-10-13 の原典確認）。帰属の誤りなので使わない。言うなら「支持集合の組合せ爆発」。

そもそも本研究の定式化は純粋な最大ハンズオフ問題ではない

これも先に開示すべき点である。本研究が解いているのは次の問題である。

  • L1 を課す対象が入力 u ではなく参照速度からの補正 δu（第9節）
  • 追従誤差の二次コストと移動抑制項が併存する（rover/mpc_core.py:82-92）

したがって L0 最適性そのものは本研究の主張ではない。L1 を使う理由は「罰金が原点で角をもつため厳密なゼロを生む」（第8節）という性質であり、δu = 0 に張り付く区間を作ることが目的である。L0 は「やりたいことの定式化」として参照するが、成立を主張する対象ではない。

卒論に反映する 4 項目（未実施）
  • §2.6 の bang-off-bang の記述を実測値（9/11 が ±1・2 成分が中間値）に直す ── chapter2.md:294-295
  • §2.5 の等価性の論拠を [6] 単独から [6] ＋ S8 の数値検証に差し替える
  • §8.2(6b) を「未実施の提案」から「実施済み・結果」に書き換える
  • L1 解の非一意性（第7節）を §2.6 または第7章の限界に 1 項として足す
このほか、第3節の不等式は「上限 1 の箱」が対称にかかる §2.6 の式 (2.13) で成り立つ。§3.4 の MPC は制約が実速度 |u_nom + δu| ≤ u_max に付いており δu の可動範囲が左右非対称になるため、等価性の議論は §2.6 の定式化で行い、§3.4 では「L1 項は ‖δu‖₀ の凸緩和として入っている」までにとどめるのが安全である。

口頭で 30 秒で言う骨

本来解きたいのは「アクチュエータを動かしている時間を最小化する」問題で、これは入力の L0 ノルム最小化（maximum hands-off control）に当たります。ただし L0 は支持集合の組合せになるため、圧縮センシングと同じ緩和で L1 に置き換えます。

一致の十分条件は可到達性と A の正則性ですが、本研究の対象系は A が冪零でこれを満たしません。「L1 最適解が bang-off-bang なら L0 最適解でもある」という別経路もありますが、実測すると §2.6 の解は非ゼロ 11 成分のうち 9 個が飽和値で2 成分が中間値、厳密な3値ではないため前提を満たしません。

そこで L0 最小の支持を総当たりで求め、その上で L1 最適値が達成されることを数値で確認しました（検証した全6事例で成立）。したがって L0 最適性は一般には主張せず、検証した事例で成り立つという限定で述べています。
