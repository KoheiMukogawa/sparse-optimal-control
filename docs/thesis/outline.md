### 論文の主軸（確定・変更しない）

> **「スパース制御（L1）を実機で成立させる条件は何か」**

一本の線:
ナイーブ L1 が実機遅延（約200 ms）下で bang-bang チャタを起こすことを**実機で示し**、
原因が入力遅延であることを **sim で定量再現**し、`move_suppress=2.0` で**消したことを実機で確認**し、
その sim が実機を**全指標10%以内で予測した**。

**正直に報告する点**: 総合 RMSE・終点誤差では **L2-MPC が最良**であり、提案手法の L1 は勝っていない
（第6章で隠さず報告 → 第7章で「L1 が何を買っているか」として位置づける）。

# 第2章 理論的背景（目安 7 p）

## 2.1 経路追従制御の定式化と古典的フィードバック（Kanayama 法）
- **主張**: 経路追従は参照姿勢に対する誤差 $z=(x_e,y_e,\theta_e)$ をロボット座標系で定義し
  ゼロへ収束させる問題として書ける。Kanayama 法はこの誤差に静的フィードバックを与える古典手法で、
  本研究のベースラインとなる。
- **図表**: 図2.1 参照姿勢と誤差 $(x_e,y_e,\theta_e)$ の幾何。
  式(2.1) 誤差の定義、式(2.2) Kanayama 制御則。
- **出所**: `docs/論文解説_figs/fig_geom.png`、実装 `rover/follower_core.py`
  （`tracking_error` / `kanayama_cmd`）、原論文 `data/paper/A stable tracking control
  method for an autonomous mobile robot.pdf`
- 1.0 p

## 2.2 最適制御と L2 正則化 — 「なめらかに動かす」設計
- **主張**: 標準的な最適制御は入力の二乗和を最小化するため、解は連続的でゼロにならず、
  結果として「常に少し動かし続ける」入力になる。
- **図表**: 図2.2 ペナルティ関数の形状比較（$|u|^2$ / $|u|$ / $\|u\|_0$）。
- **出所**: `docs/論文解説_figs/fig_norms.png`
- 0.8 p

## 2.3 スパースモデリングと L0 ノルム
- **主張**: 「どれだけ動かしたか」ではなく「動かした時間（回数）」を測る量が L0 ノルムであり、
  その最小化が入力を時間方向に疎にする。圧縮センシングの発想の制御への輸入である。
- **図表**: 表2.1 L2 / L1 / L0 の最小化がもたらす解の性質の対比。
- **出所**: `data/paper/最適制御とスパースモデリング.pdf`（永原 2017）に基づく整理
- 0.8 p

## 2.4 Maximum Hands-off Control の定義と動機
- **主張**: L0 最小＝ゼロ入力区間の最大化＝「最大限手を放す」制御であり、
  停止中はエネルギーを消費しないという物理的動機を持つ。
- **図表**: 式(2.3) 連続時間の最大ハンズオフ問題の定義。
- **出所**: 永原 2017（`data/paper/`）
- 1.0 p

## 2.5 L0/L1 等価性と bang-off-bang 解
- **主張**: 正規性条件のもとで L1 最適制御は L0 最適（最大ハンズオフ）制御と一致し、
  解は $\{+u_{\max},0,-u_{\max}\}$ の3値をとる bang-off-bang 構造になる。
  これが「解ける凸問題を解くだけで最も疎な制御が得られる」という本理論の核である。
- **図表**: 図2.3 bang-off-bang 解の模式波形。図2.4 L1 が生む軟しきい値（不感帯）作用。
- **出所**: `docs/論文解説_figs/fig_bob.png`, `docs/論文解説_figs/fig_soft.png`
- 1.2 p

## 2.6 離散時間定式化と予備数値実験（オープンループ）
- **主張**: 終端到達条件は $\Phi z=\zeta$ の線形制約に書け、問題は
  $\min\|z\|_1$ s.t. $\Phi z=\zeta$, $\|z\|_\infty\le 1$ という LP/凸問題になる。
  差動二輪の運動モデルでこれを解くと、操舵入力の **78%（39/50 ステップ）が厳密にゼロ**となり、
  理論の bang-off-bang が本研究の対象機体でも再現される。
  **スパース性指標として $\delta\omega$ のゼロ率を採る根拠もここで述べる**: $B_d$ の構造から
  $\delta v$ と $\delta\omega$ は完全に分離し、$\delta v$ 側の部分問題は終端制約が
  $\sum\delta v = -\delta x_0/h$ の1本だけで**退化している**（同符号でありさえすれば
  配り方によらず L1 が同値＝最小解が無数にある）。$\delta v$ のスパース性はソルバー依存であり
  問題の性質ではない。意味のあるスパース性は $\delta\omega$ 側にある。
- **図表**: 表2.2 予備シミュレーション条件（h=0.1 s, V=1.0 m/s, n=50, 初期誤差 (2.0 m, 1.0 m, 30°)）。
  図2.5 誤差の収束と操舵入力 $\delta\omega$（78% がゼロ、±最大と0の3値）。
- **出所**: **`results/2026-07-26_openloop_bangoffbang/`（summary.md, series.csv,
  bangoffbang.png, notes.md）、実装 `rover/openloop_sparse.py`**／
  定式化と当時の記録は `docs/作業記録/2026-04-28_sparse_control_sim.md`
- **注記**: 当時の実装コードと図はリポジトリに存在しなかったため定式化から再実装した。
  **記録値（δω ゼロ 39/50・L1 30.65）を完全再現**しており、78% という数値は検証済み。
- 1.4 p

## 2.7 MPC への拡張と本研究の位置づけ

# 第3章 提案手法（目安 7 p）

## 3.1 車両モデル（差動二輪運動学）
- **主張**: 対象は差動二輪の非ホロノミック運動学モデルであり、制御入力は並進速度 $v$ と
  角速度 $\omega$ の2入力である。
- **図表**: 式(3.1) $\dot x=v\cos\theta,\ \dot y=v\sin\theta,\ \dot\theta=\omega$。
  表3.1 実機の物理諸元（トレッド `ROVER_D=0.1514` m、$v_{\max}=0.15$ m/s、$\omega_{\max}=2.0$ rad/s）。
- **出所**: `rover/mpc_core.py`（`v_max`/`w_max`）、`rover/mpc_follower.py`（`V_MAX`/`W_MAX`）、
  `CLAUDE.md`（`ROVER_D=0.1514`）
- 0.8 p

## 3.2 参照軌道まわりの誤差ダイナミクスと離散化
- **主張**: 参照速度 $(v_r,\omega_r)$ まわりで線形化した誤差ダイナミクスを1次オイラーで離散化し、
  毎ステップ $(A,B)$ をパラメータとして更新することで、同一の QP を係数差し替えだけで解き直せる。
- **図表**: 式(3.2) 連続時間誤差ダイナミクス
  $\dot x_e=\omega_r y_e-\delta v,\ \dot y_e=-\omega_r x_e+v_r\theta_e,\ \dot\theta_e=-\delta\omega$。
  式(3.3) 離散化 $A=I+T_sA_c,\ B=T_sB_c$。
- **出所**: `rover/mpc_core.py::error_dynamics`
- 1.0 p

## 3.3 L2-MPC の定式化（ベースライン）
- **主張**: 状態コスト $Q$、入力コスト $R$、終端コスト $Q_f$（等式制約でなくソフト化して
  実行不可能を回避）、実速度への box 制約からなる標準形 MPC を、L1 の効果を測る「ものさし」として先に構築する。
- **図表**: 式(3.4) L2-MPC の最適化問題。
  表3.2 重み設定 $q=(10,10,1)$, $r=(1,1)$, $q_f=10Q$, $N=15$, $T_s=0.1$ s。
- **出所**: `rover/mpc_core.py::MPCFollower.__init__`
- 1.2 p

## 3.4 L1 化 — なぜ $u$ でなく補正 $\delta u$ を penalize するのか
- **主張**: 目的関数の1項を $\lambda\|\delta u_k\|_1$ に差し替えるだけで L2↔L1 を切り替えられ、
  同一骨格・同一制約での公平な比較が成立する。penalize 対象を**参照速度からの補正 $\delta u$**
  とすることで、巡航速度は維持したまま「補正を打つ瞬間だけ動かす」スパース操舵が得られる
  （$u$ 自体を penalize すると走行そのものが止まってしまう）。
- **図表**: 式(3.5) L1-MPC の目的関数。図3.1 コスト関数の該当1行の対比（`cp.norm1` / `cp.quad_form`）。
- **出所**: `rover/mpc_core.py`（79〜85 行の分岐）
- 1.2 p

## 3.5 移動抑制項 `move_suppress` の導入
- **主張**: 実機遅延下の bang-bang チャタを抑えるため、入力変化率
  $\Delta\delta u_k=\delta u_k-\delta u_{k-1}$（$k=0$ は前回実適用値）の二次ペナルティを追加する。
  既定値 0 で従来挙動と完全に一致するため後方互換であり、L1 のスパース性を壊さずにチャタのみを抑制する。
- **図表**: 式(3.6) 移動抑制項付き目的関数。図3.2 $w_{ms}$ が入力系列に与える作用の模式図。
- **出所**: `rover/mpc_core.py`（86〜89 行、`du_prev` パラメータ）。設計根拠は第5章 5.7 節。
- 1.0 p

## 3.6 設計パラメータの選定指針（$\lambda$, $w_{ms}$, $N$）
- **主張**: $\lambda$ は到達性を保つ 0.25〜2 を採用域とし（$\lambda\ge3$ で追従破綻）、
  実機は $\lambda=0.3$ を用いる。$w_{ms}$ は 2.0 を採用する。
  **$w_{ms}=2.0$ の根拠は「遅延2stepでの最適」ではなく「遅延3〜4stepまで耐える遅延マージン」である**
  （$w_{ms}=0.5$ は遅延2stepでは同等だが遅延4stepで $\Sigma|u|$ 16.16 とチャタへ逆戻りし、
  $w_{ms}=2.0$ は 7.52 に留まる）。$N$ は求解時間の実現可能性から上限 30、常用 15 とする。
- **図表**: 表3.3 設計パラメータの採用値と根拠節の対応表。
- **出所**: `results/2026-07-26_lambda_ms_grid/`（λ×$w_{ms}$ 遅延下グリッド）、

## 4.3 評価指標の定義
- **主張**: 卒論4指標（追従精度・消費エネルギー代理・入力スパース性・計算負荷）に加え、

## 5.2 $\lambda$ の選定 — スパース性と追従精度のトレードオフ
- **主張**: sim の $\lambda$ スイープにより、**$\lambda\approx0.25$ が RMSE・$\Sigma|\delta u|$・
  ゼロ率の3軸すべてで L2 を上回るスイートスポット**であり、$\lambda$ の増加とともに
  $\Sigma|\delta u|$ は単調減少するが RMSE は悪化し、**$\lambda\ge3$ で到達性が破綻**することを示す。

  λ=1 が谷（7〜8 cm）になる**ことが分かった。1次元スイープでは観測できない構造であり、
  設計点の選定は2次元で行う必要がある。

## 5.6 原因の特定 — 入力遅延の注入による定量再現
- **主張**: **理想 sim では L1 はチャタらない**（L字で $\Sigma|u|$ 4.41、反転 0）ため、
  原因は sim に無く実機にあるもの＝求解・通信・速度ループの遅延であると仮説を立てた。
  差動二輪 sim に入力遅延を注入すると、**遅延2ステップ（約200 ms）で
  $\Sigma|u|$ 18.49・反転 19** となり、実機実測（20.71・15）とほぼ定量一致した。
  一方 L2 は全遅延条件で反転 0 と頑健である。よって**チャタの機序は「L1 の bang-bang 的切替入力が
  遅延下で限界振動（スライディングモード的チャタ）化する」ことにある**と特定した。
  さらに L1 は求解時間が L2 の約2倍であり、**自ら遅延を増やす悪循環**を持つ。
  **遅延を0〜4stepまで伸ばすと、ナイーブ L1 は遅延1stepまでは無事（反転2）で
  2stepで急激に破綻する（反転19）しきい値的な壊れ方をする**一方、
  **L2 は遅延4stepまで反転0を保つ**。実機の推定遅延がちょうど破綻域に入っていたことになる。
- **図表**: 図5.4 遅延ステップ数に対する反転回数・$\Sigma|u|$・RMSE・ω0率（6条件、0〜4step）。
  表5.8 遅延スイープ（遅延0〜4 step × 6条件、実機実測との対比つき）。
- **出所**: `results/2026-07-26_delay_sweep/`（delay.csv, table.md, delay_sweep.png, notes.md）、

## 5.7 対策の設計 — 移動抑制項の sim による設計
- **主張**: 入力変化率ペナルティ（移動抑制 $w_{ms}$）を導入し、遅延2ステップ条件で $w_{ms}$ を掃引した結果、
  **$w_{ms}=2.0$ でチャタが実質消失（反転 19→1、$\Sigma|u|$ 18.49→5.01、飽和 36%→4%）しつつ、
  ω ゼロ率 89% とスパース性が保たれる**ことを確認した。RMSE もむしろ改善する（3.12→1.90 cm）。
  理想（遅延0）条件でも $w_{ms}=2.0$ はスパース性をほぼ損なわない（ゼロ率 95%→93%、
  $\Sigma|u|$ 4.41→4.43）ため、遅延の有無によらず安全に採用できる。
  **ただし $w_{ms}=2.0$ を選ぶ理由は遅延2step時点の性能ではない。** 遅延2stepでは
  $w_{ms}=0.5$ でもほぼ同等（反転2 vs 1）だが、遅延を3〜4stepに伸ばすと
  $w_{ms}=0.5$ は崩壊し（反転9・$\Sigma|u|$ 16.16）、$w_{ms}=2.0$ は保つ（反転4・7.52）。
  **$w_{ms}$ が買っているのは遅延マージンである。**
  また対策は遅延を無効化するのではなく破綻を遅らせているにすぎない
  （$w_{ms}=2.0$ でも ω0率は遅延とともに 93→69% と低下する）。

## 5.10 本章のまとめ — L1 を実機で成立させる条件
- **主張**: 本章の一連の結果から、スパース制御を実機で成立させる条件は
  **(a) 入力遅延に対する明示的な配慮（移動抑制または遅延補償）**、
  **(b) 求解時間が遅延の一部を構成することの認識（L1 は L2 の 1.5〜2 倍）**、
  **(c) 操舵を要する経路での検証（直線・空転では問題が顕在化しない）** の3点に整理される。

# 第7章 考察（目安 5 p）

## 7.1 提案手法は何を買っているのか
- **主張**: 総合順位で L2 に及ばないという事実の上で、L1+移動抑制が確かに獲得しているものは
  **(1) 入力のスパース性（ゼロ入力率 0.88 で全条件中最良、L2 0.87・Kanayama 0.65 を上回る）**、
  **(2) 最終姿勢の精度（$|\theta|$ 1〜10°、L2 は一貫して 16〜22° 傾く）** の2点である。

  可能性を示唆する。畝の終端で次の作業姿勢へつなぐ農業用途では姿勢精度の価値は小さくない。

- **主張**: 本研究で特定した機序（切替型の最適入力が遅延下で限界振動化する）は、

## 7.4 sim-to-real の予測性が持つ方法論的意味
- **主張**: 遅延という1つのモデル要素を加えるだけで sim が実機を全指標10%以内で予測できたことは、
  「何が実機と理想の差を作っていたか」の同定が正しかったことの強い証拠である。
  同時に、実機時間が希少な研究環境において**設計を sim で先に閉じられる**ことを意味する。
  実際、移動抑制の重みは sim で設計され、実機では1度の確認で済んだ。

### 7.4.1 単一条件での最適化という落とし穴
- **主張**: sim で設計を閉じる方法には固有の危険がある。遅延2stepという**単一条件**で
  λ×$w_{ms}$ を最適化すると λ=2 / $w_{ms}=0.5$ が全指標最良と読めるが、
  遅延を動かすとこの点は**遅延2stepでのみ現れる偶然の谷**であることが分かる
  （RMSE は遅延0/1/3/4step で 11〜14 cm）。
  同様に「$w_{ms}=0.5$ で足りる」という読みも遅延2stepでのみ正しい。
  **設計点は、設計変数の面だけでなく想定条件の幅に対しても評価しなければならない。**
  本研究が $\lambda=0.3$ / $w_{ms}=2.0$ を採るのは、この幅で評価した結果である。
- **図表**: 図7.2 λ=2 の RMSE が遅延2stepでのみ落ち込む様子（見かけの最適の可視化）。
- **出所**: `results/2026-07-26_lambda_ms_grid/notes.md`（撤回の追記つき）、
  `results/2026-07-26_delay_sweep/notes.md`

- **主張**: odom 基準の評価では L1 と L2 の真の差が見えず、結論が逆転しうる
  （直線2 m では odom 上 L2 最良だが真値では L1 最良）。

## 7.6 本研究の限界
- **主張**: 以下を明示的に限界として述べる。
  1. **反復数が少ない**（n=3）。外れ値率・分散の議論には不足（R9）。
  2. **入力遅延を直接測っていない**。約200 ms は求解時間と通信からの推定である（R5）。
  3. **消費エネルギーは $\Sigma|u|$ という代理指標**であり、実電力を測っていない（R8）。
  4. **外乱条件での評価が未実施**であり、スパース制御の主要な想定利点を検証できていない（R1）。
  5. **屋内フローリング1種のみ**であり、圃場を模した路面での検証がない（R11）。
  6. ゼロ入力率は実操舵 $\omega$ のゼロ率であり、L1 が penalize する $\delta u$ のゼロ率と厳密には一致しない。
  7. 6/13 の L2 単発（終点 2 cm・0°）と 7/15 の L2（12.7 cm・19°）が不一致であり、
     単発計測は信頼できない（n=3 の値を採用する根拠）。

# 第8章 結論と今後の課題（目安 2 p）

## 8.1 結論
- **主張**: 本研究は「スパース制御を実機で成立させる条件は何か」に対し、
  **入力遅延への配慮が成立の必須条件である**と結論する。
  ナイーブな L1-MPC は実機遅延（約200 ms）下で bang-bang チャタを起こし
  （$\Sigma|u|$ が L2 の4.5倍・反転18回）、その機序は遅延注入 sim で定量再現でき、
  入力変化率ペナルティ（$w_{ms}=2.0$）により反転1回・$\Sigma|u|$ 5.02 へ消失した。
  対策後もゼロ入力率 0.88 とスパース性は保たれる。
  ただし**総合的な追従精度では L2-MPC が最良であり、提案手法はゼロ入力率と最終姿勢精度において
  優位を示すにとどまる**。
- 1.2 p

## 8.2 今後の課題
- **主張**: (1) 外乱条件（積載・路面）での評価によりスパース制御の想定利点を検証する、
  (2) 遅延の直接計測と遅延補償（既知遅延分の状態予測）による別解の比較、
  (3) 実電力計測による省エネ効果の直接検証、
  (4) 反復数を増やした外れ値率の評価、
  (5) CasADi+IPOPT による非線形 MPC との比較。
- **出所**: `docs/research_plan.md` P4、`results/2026-07-15_Lturn_batch_compare.md` 次へ節

## 想定質問への備え（審査対策メモ）

| 想定質問 | 用意する答え（根拠節） |
|---|---|
| なぜ L2 が良いのに L1 を研究するのか | 本論文の問いは優劣ではなく「成立条件」。かつ L1 はゼロ入力率と最終姿勢精度で最良（7.1） |
| L1 は計算が重いのでは | その通りで p95 で L2 の 1.5 倍。しかも自ら遅延を増やして自らの安定性を損なう（5.6、7.2） |
| 実機遅延 200 ms の根拠は | 求解 p95 と通信・速度ループからの推定。直接実測は今後の課題（5.6 注記、7.6、R5） |
| sim が実機と一致したのは偶然では | 4条件×全指標で 10% 以内、l1_ms2 は反転 1 vs 1 まで一致（5.9） |
| 省エネと言うが電力を測ったか | 測っていない。$\Sigma|u|$ は代理指標である（4.3 注記、7.6、R8） |
| 78%と言うが $\delta v$ は疎でないのでは | その通り。$\delta v$ 側の部分問題は退化しており最小解が無数にあるためスパース性はソルバー依存。意味のあるスパース性は $\delta\omega$ 側にある（2.6） |
| 外乱下の評価は | 実験条件は設計済みだが未実施（6.7、8.2、R1） |
| なぜ λ=0.3 / $w_{ms}$=2.0 なのか | 遅延2step下で λ×$w_{ms}$ を2次元掃引し、さらに遅延を0〜4stepまで振って選んだ。$w_{ms}$=2.0 は遅延2step時点の性能ではなく遅延3〜4stepまでの**マージン**を買っている（3.6、5.7） |
| $w_{ms}$=0.5 でも遅延2stepでは同等では | その通りだが遅延4stepで崩壊する（$\Sigma\|u\|$ 16.16 vs 7.52）。単一条件での最適化は見かけの最適を掴むという教訓そのもの（7.4.1） |
