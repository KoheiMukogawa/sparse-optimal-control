### 指摘の具体化（ユーザー補足・2026-10-22）

「MPCと経路予測では情報量が違うので、正しい比較研究にならないのではないか」という意見。
以下の回答案は比較対象がKanayama則である場合のもの。「経路予測」が別の手法を指す場合は再確認する。

### コード確認に基づく回答準備

- MPCも経路追従を行う制御手法なので、比較の表現は「MPC対経路追従」ではなく「MPCによる経路追従対Kanayama則による経路追従」とする。
- `path_follower.py` と `mpc_follower.py` はともに `reference_pose` と `tracking_error` を使う。参照点は経路射影点からlookahead先（既定0.15m）に置く。Kanayama側も経路の先の情報を全く使わないわけではない。
- 現行 `MPCFollower.command` に渡すのは現在の誤差と参照速度。未来N点の参照経路列を渡してはいない。現在の参照速度で作る同一A,Bを予測区間で使い、モデルから未来の誤差を予測する。ノードでは `w_r=0.0` を渡す。
- したがって「MPCだけが未来の曲がり角の経路列を与えられている」という説明は現行コードには当てはまらない。ただしモデルによる予測・制約処理・最適化の有無は異なる。
- Kanayamaとの比較はシステム全体の性能比較として扱う。この比較だけから「L1正則化の効果で精度が改善した」とは主張できない。
- L1の効果は同じMPC内のL2/L1で評価し、移動抑制の効果は同じL1-MPCの移動抑制なし/ありで評価する。
- L1特有の移動抑制効果まで主張するなら、L2+移動抑制を追加し、L1/L2×移動抑制なし/ありの4条件で比較する。
- 条件の監査項目: 実行時の参照点・状態情報・制御周期・速度/入力上限・ゴール条件・遅延・初期状態・調整方法。既定値ではKanayamaノード20Hz、MPCノード10Hzと異なる。バッチ設定はcommon.rate=10Hzだが、過去走行の適用値は起動引数または記録で確認する。

## 2. 凸最適化問題を何で解いたか

### 比較設計の検討追記

- Kanayama則はスパース化の効果検証には必須でない。従来方式との参考比較として残すか、主結果から外すかを検討中（削除は未決定）。
- MPCは予測・最適化・先頭入力の適用を繰り返す枠組みで、L2コストは必須ではない。
- 「入力ペナルティなしMPC」は追従誤差の二次コストと終端コストを残し、入力のL1/L2項をゼロにするもの。二次コストそのものが無いわけではない。入力制約は維持する。入力の大きさを直接罰しないため、強い入力や不安定な切替、解の非一意性が生じうるが必然ではない。
- 二次コストを全く使わず、誤差と入力をL1ノルムで評価するMPCも構成可能。線形モデル・線形制約なら補助変数を用いてLPにできる。ただし誤差コストまで変えると今回のL1入力項の効果を分離する比較にはならない。
- 候補: 入力ペナルティなしを補助比較とし、主比較はL2/L1×移動抑制なし/ありの4条件。モデル・参照情報・制約・ホライズン・周期・調整手順を共通化する。採用条件は未決定。
- 理論確認: https://www.mathworks.com/help/mpc/gs/what-is-mpc.html 、 https://www.do-mpc.com/en/latest/api/do_mpc.controller.MPC.html 、 https://web.cvxr.com/cvx/doc/quickstart.html

- 使用したモデリングツールとソルバ、および問題をどの形式に変換して解いたかを説明する。
- これまでの確認では CVXPY で記述し OSQP で求解。次回の回答前に、該当実験のコード・設定と照合する。

## A. 「L1 を説明するのに L0 をどう使うのか」（指摘3）

### A-0. 口頭で30秒で言う骨

> 本来解きたいのは「アクチュエータを動かしている**時間**を最小化する」問題で、
> これは入力の $L^0$ ノルム最小化（maximum hands-off control）に当たります。
> ただし $L^0$ は非凸で支持集合の組合せになるため、圧縮センシングと同じ緩和で
> $L^1$ に置き換えます。**両者が一致する十分条件は可到達性と $A$ の正則性ですが、
> 本研究の対象系は $A$ が冪零（$A^2=O$）でこれを満たしません。**
> そこで「$L^1$ 最適解が bang-off-bang であれば $L^0$ 最適解でもある」という
> 別経路に依拠し、2.6 節の数値実験で $\delta\omega$ が $\{-1,0,+1\}$ の3値を
> とる bang-off-bang 構造を確認しています。したがって **$L^0$ 最適性は
> 一般には主張せず、その初期値において成り立つという限定で述べています。**

### A-1. $L^0$ の役割（なぜ $L^0$ から話を始めるのか）

- $L^0$ ノルムは「入力が**ゼロでない時間**の測度」（本文 2.3 節・chapter2.md:119）。
  $L^2$ が「大きさ」、$L^1$ が「総量」を測るのに対し、$L^0$ は**動かした時間**を測る
- 研究の動機（常時操舵による摩耗・消費）に対応する量は $L^0$ であり、
  $L^0$ 最小化＝**アクチュエータを止めている時間の最大化**（chapter2.md:182）。
  これが maximum hands-off control の定義そのもの
- つまり **$L^0$ は「本当に最小化したい量」として登場し、$L^1$ はその計算可能な代理**。
  この順で説明すると「なぜ $L^1$ なのか」が後から効く

### A-2. 等価性をどこまで主張できるか（ここが質問の核心）

| | 内容 | 本研究 |
|---|---|---|
| 定理1 [3] | 正規性のもとで $L^0$ 最適制御と $L^1$ 最適制御は**一致** | 使えない |
| 十分条件 | 可到達性 ＋ **$A$ の正則性** | **$A$ は冪零**（$A^2=O$・$\det A=0$・$\mathrm{rank}\,A=1$）→ **満たさない** |
| 単入力への縮約 | 定理は単入力を想定 | $\delta\omega$ のみに縮約すると**可到達性も失う**（rank 2 < 3） |
| 代替経路 [6] | **$L^1$ 最適解が bang-off-bang なら $L^0$ 最適解でもある** | **これに依拠**（Ikeda–Nagahara, ACC 2016） |
| 数値的裏づけ | 2.6 節: $\delta\omega$ が $\{-1,0,+1\}$ の3値のみ・$L^1$ 値 30.65 | **bang-off-bang を確認**（chapter2.md:294-296, 376-385） |

**言ってよいこと**: 「得られた $L^1$ 解は bang-off-bang なので、その初期値においては
$L^0$ 解でもある」。本文 2.5 節はこの限定付きで書いてある。

**言ってはいけないこと**（本文からも削除済み）:
- 「定理1 により一致する」── 十分条件を満たさない
- 「$L^1$ なら必ず $L^0$ 最適」「本研究の MPC 解は必ず bang-off-bang」── 初期値依存
- **「$L^0$ 最小化は NP 困難」── 参考文献 [3] の本文にこの語は無い**（2026-10-13 の原典確認）。
  帰属の誤りなので使わない。言うなら「**支持集合の組合せ爆発**」

### A-3. さらに正直に言うべき限定（聞かれたら先に出す）

本研究の定式化は**純粋な maximum hands-off 問題ではない**:

- $L^1$ を課すのは入力 $u$ ではなく**参照速度からの補正 $\delta u$**
- 追従誤差の二次コストと**移動抑制項 $\lambda_{ms}\|\Delta\delta u\|^2$ が併存**する
  （`rover/mpc_core.py:82-92`）

→ したがって **$L^0$ 最適性そのものは本研究の主張ではない**。
$L^1$ を使う理由は「ペナルティが原点で微分不可能な角をもつため**厳密なゼロを生む**」
（chapter2.md:228-229）という性質であり、$\delta u=0$ に張り付く区間を作ることが目的。
**$L^0$ 最適性は「やりたいことの定式化」として参照するが、成立を主張する対象ではない。**

### A-4. 想定追加質問

| 質問 | 回答 |
|---|---|
| なぜ $L^0$ を直接解かないのか | 支持集合の組合せになる。$N=15$・2入力なら on/off の割り当てが $2^{30}$ 通り。小さい $N$ でしか総当たりできない |
| 等価性が無いならなぜ $L^1$ か | 目的はスパース性（止まっている時間を増やすこと）そのもので、$L^0$ 最適性は目的ではない。$L^1$ は凸なので実時間で解ける（OSQP・N=15 で p95 18.0ms） |
| bang-off-bang は初期値依存ではないか | そのとおり。本文は「**その初期値においては**」と限定している。一般の主張はしていない |
| $L^0$ はノルムか | 厳密には斉次性を満たさずノルムではない。慣例に従い $L^0$ ノルムと呼んでいる |

### A-5. この回答を強くする補強（実機不要・1日）

これがあれば「等価性は定理からは出ないが、**自分の系では数値的に支持される**」と言える。

## B. 「L1/L2 と Kanayama を制御則の比較対象に並べるのは妥当か」（指摘1）

### B-0. 口頭で30秒で言う骨

> ご指摘のとおり、Kanayama 則と MPC では予測モデル・制約処理・最適化の有無が
> まとめて違うため、**この比較から「L1 正則化の効果」を分離することはできません。**
> そこで役割を分けています。**Kanayama は従来方式に対する位置づけを示すベースライン**で、
> **研究の主張は、同じモデル・同じホライズン・同じ制約・同じ参照点を使う
> L2-MPC と L1-MPC の対照**、および **L1-MPC の移動抑制なし/あり**の対照に置いています。
> なお現行実装では両手法が同じ方法で参照点を選び、**MPC だけに未来の参照経路列を
> 与えているわけではありません**（`w_r=0` で渡しています）。

### B-1. 比較を4層に分ける（これが回答の骨格）

| 層 | 対照 | 何が分離できるか | 主張に使うか |
|---|---|---|---|
| 1 | Kanayama vs MPC 系 | 系全体の性能差（予測・制約・最適化が**まとめて**違う） | **文脈のみ**。L1 の主張には使わない |
| 2 | **L2-MPC vs L1-MPC** | **正則化項だけ**が違う（モデル・N・制約・参照点・周期は共通） | **ここが本研究の主張** |
| 3 | L1-MPC の ms なし vs あり | 移動抑制の効果 | 対策の有効性 |
| 4 | **L1/L2 × ms なし/あり（2×2）** | 移動抑制が **L1 特有**か、L2 でも効くのか | **未実施・追加すべき** |

層4 は指摘への直接の回答になる。**`rover/mpc_core.py:89` の `move_suppress` は
`if reg == "l1"` の外にあり `reg` に依存しないので、L2+移動抑制は追加実装なしで成立する。**

### 【実施済み・2026-11-26】層4 を遅延0〜4step で回した → `results/2026-11-26_2x2_ms_sim/`

`rover/sweep_delay.py` に `l2_ms2` を追加して 4条件 × 遅延5点を sim で取得（全20条件で到達）。
**これが指摘1への回答の中核データになる。**

| | 遅延0→4 の Σ\|u\| | 飽和率の最大 | 反転の最大 | ω0率の最小 |
|---|---|---|---|---|
| L2 | 4.54 → 4.71（**+4%**） | 3.0 % | 1 | 83.5 % |
| L2 + ms2 | 4.56 → 4.85（ほぼ同じ） | **0.0 %** | 1 | 83.6 % |
| L1 | 4.41 → **22.63（5.1倍）** | **43.8 %** | **19** | **49.5 %** |
| L1 + ms2 | 4.43 → 7.52（**3倍に抑制**） | 5.0 % | 4 | 69.0 % |

**言えるようになったこと（3点）**

1. **遅延そのものは L2 を壊さない**（Σ\|u\| +4%・反転0〜1）。
   → 破綻は「MPC という枠組み」の問題ではない
2. **同一モデル・同一制約・同一参照点で正則化項だけを L2→L1 に替えると、
   遅延2step で破綻する**（Σ\|u\| 4.2倍・反転19回・飽和35.5%・ω0率 95.3→56.4%）。
   → **L1 固有の病理であることが対照つきで示せた**
3. **移動抑制は L1 にだけ効く。** L2 側では Σ\|u\| も反転もほぼ動かず、
   **RMSE は 1.51→2.14 cm と逆に悪化**する（飽和が 0% に下がるだけ）。
   → 移動抑制は「MPC一般の安定化」ではなく **L1 のチャタ対策**である

**正直に言う点**: L1+ms2 の RMSE は遅延1で 3.28 cm と非単調（遅延0=1.01・遅延2=1.90 より悪い）。
主張は「**遅延0〜4の全域で破綻しない**」に置き、特定遅延での優劣には置かない
（2026-07-26 の教訓: λ=2 の最良は遅延2stepのみの偶然の谷だった）。

### B-3. 統制できていない条件（**先に開示する**）

**実機バッチでは Kanayama が 20 Hz、MPC が 10 Hz で走っている。**
`rover/exp_backends.py:180-190` の `node_command` は、kanayama 枝に `rate` を渡さず
`path_follower.py` の既定値 20 Hz のまま起動する（MPC 枝だけ `common.rate`＝10 Hz を渡す）。

これをどう扱うか（**この順で答える**）:

1. **指標が周期に歪められていないことを示す**。
   $\Sigma|u|$ は `dt` を掛けた**時間積分**（`exp_metrics.py:39-45`: `dt=(t1-t0)/(len-1)`、
   `sum_u = Σ|v|·dt + Σ|ω|·dt`）。ゼロ率は標本比＝時間比の推定（同:47）。
   **どちらも標本数そのものには比例しない**ので、周期差が系統的なバイアスにならない
2. **周期差は Kanayama に有利**である（フィードバックが2倍速い）。
   その有利を与えてなお、横偏差 RMSE は **Kanayama 11.26 cm 対 MPC 1.5〜3.5 cm**
   （chapter6.md:71,80）。**結論を覆す方向には働かない**
3. **修正は1行**（kanayama 枝に `-p rate:=` を渡す）だが、**再走行には実機が必要**。
   したがって卒論では**実験条件表に周期を明記し、7.6 節の限界に1項として書く**

### B-4. 調整労力の対等性（これも聞かれる）

- Kanayama のゲインは $k_x=0.5,\ k_y=5.0,\ k_\theta=3.0$ で、`path_follower.py` の
  **既定値のまま**（`exp_backends.py:34` の `KAN_GAINS` も同値）。安定条件は 2.1 節の命題1・命題2
- MPC の重みは $Q=\mathrm{diag}(10,10,1)$ を**試行により決定**（3.4 節）
- → **両者のチューニング労力は対等でない。** 「Kanayama を本気で詰めればもっと良くなる余地がある」
  ことは認めたうえで、**だからこそ L1 の主張を Kanayama 比較に載せていない**と答える

### B-5. 本文での位置づけは既に正しい（確認済み）

- chapter6.md:9「ベースラインである Kanayama 法および L2-MPC と定量的に比較する」
- chapter6.md:49-50 で Kanayama を「古典的な非線形フィードバック則。**最適化を行わない**」、
  L2-MPC を「**本研究のベースライン**」と明記
- chapter6.md:91-93・125-127 で Kanayama は「$\Sigma|u|$ は小さいが**常時わずかに操舵し続ける**」
