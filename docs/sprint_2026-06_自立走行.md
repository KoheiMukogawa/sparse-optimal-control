# 4日スプリント計画: 自立走行（2026-06-12策定）

ゴール: **LiteRoverが参照経路をセンサフィードバックで自動追従する**（teleopなし）。

## スコープの割り切り

- **SLAM・AMCL: やらない。** /odomのみで自己位置とする（屋内・短距離ならドリフト許容）
- **DDS（ラップトップ↔RPi通信）: やらない。** 全ノードをRPi上で実行し、通信問題を回避
- **制御則は二段構え:** まずKanayama制御則（解析解・計算瞬時）で自立走行を確定させ、その後L1-MPCに差し替える。Day 3で間に合わなければKanayamaまでで「自立走行達成」とする

ブランチ: `exp/autonomous-drive`

## Day 1: 土台確認と参照経路

- [ ] RPiにssh接続、`pos_joycon.launch.py` で全ノード起動確認
- [ ] `/odom` と `/cmd_vel` の型・座標系・更新周波数を確認（`ros2 topic echo/hz`）
- [ ] teleopで直進2m→停止し、/odomの距離・角度の誤差（ドリフト）を実測
- [ ] 参照経路をYAMLで定義（まず直線2〜3m、余裕があれば直線+90度旋回）
- [ ] RPi上にワークスペース（パッケージ雛形 `sparse_control`）を作成

## Day 2: Kanayama誤差計算ノード＋追従制御で自立走行

- [ ] 誤差計算ノード: /odom + 参照経路 → 誤差 (x_e, y_e, θ_e) をパブリッシュ
- [ ] Kanayama制御則ノード: v = v_r cosθ_e + K_x x_e, ω = ω_r + v_r(K_y y_e + K_θ sinθ_e) → /cmd_vel
- [ ] 机上（ジャッキアップ）で挙動確認 → 床で直線追従テスト
- [ ] **ここで自立走行のマイルストーン達成。rosbagで記録を残す**

## Day 3: L1スパースMPCノードへ差し替え

- [ ] cvxpy（+OSQP/ECOS）をRPiにインストール、求解時間を単体計測（目安: 0.1秒周期に収まるか。短ホライズンN=10程度から）
- [ ] sparse_rover.pyのL1最適化をローリングホライズン化してノード化（入力: 誤差トピック、出力: /cmd_vel）
- [ ] 間に合わない場合の縮退: ①N短縮 ②制御周期0.2秒 ③Day 2のKanayamaで完了とし、MPCはシミュレーション課題に戻す

## Day 4: 比較走行とまとめ

- [ ] 同一経路でKanayama（L2的な常時入力）vs L1-MPCを複数回走行、rosbag記録
- [ ] ゼロ入力率・追従誤差を算出（雑でよい、後で再計算可能なよう生データ優先）
- [ ] 作業記録・handoff.md更新、研究計画（research_plan.md）のP3/P5前倒し分を反映

## 達成ライン

- **最低ライン（Day 2終了時）:** odomベースのKanayama制御で直線自立走行
- **目標ライン（Day 4終了時):** L1スパースMPCで自立走行し、比較データの初回分がある
