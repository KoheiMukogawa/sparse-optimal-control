# 研究計画（2026-06-12改訂版）

卒業研究「農業用ロボットの経路追従制御におけるスパース最適制御（Maximum Hands-off Control）」のフェーズ別計画。

## 前提

- 中間発表: 2026年9〜10月、卒論提出: 2027年2月、実機実験必須
- **比較構図: Kanayama（古典FB） / L2-MPC（標準最適制御） / L1-MPC（提案手法）の3者比較**
  - L1の効果は「同一MPC構造でコスト関数のみ変えた」L2との比較で初めて分離できる
  - Kanayamaベースラインの実機データは取得済み（2026-06-12, rosbag7本）
- 評価指標: RMSE / 消費エネルギー（Σ|u|） / 入力スパース性（ゼロ入力率） / 計算負荷（求解時間）
  - 注: L1は入力回数を減らすが**計算は増える**。そのトレードオフ定量化が貢献の柱
- 実装順序: **MPC骨格をL2で作りデバッグ → 目的関数をL1化**（cvxpyでは1行差）

## P1: MPC実装フェーズ（6/13〜7/15）

ブランチ: `exp/mpc`

### 1. 実現可能性ゲート: RPi求解時間ベンチ（最初にやる・半日）

- RPi4にcvxpy+OSQPを導入し、想定サイズのQP（状態3×ホライズンN=10〜30）の
  求解時間を計測（電源のhwmon低電圧アラームを併監視）
- 判定: 0.1秒周期に収まるN上限を把握 → 以降の設計パラメータにする
- 収まらない場合の縮退: 周期0.2秒 / N短縮 / ラップトップでのオフライン検証中心

### 2. L2-MPCシミュレーション（〜6月末）

- ローリングホライズンの骨格: 誤差ダイナミクスの離散化、入力制約、
  終端コスト（終端等式制約は実行不可能リスクがあるためソフト化）
- プラントは非線形運動学+外乱注入（test_follower_sim.pyを拡張）
- Kanayamaと同条件で追従できることを確認（MPC骨格のデバッグ完了条件）

### 3. L1化とスパース性確認（〜7月上旬）

- 目的関数を λ‖u‖₁（+状態コスト）に変更、λスイープでスパース性↔RMSEの
  トレードオフ曲線を取得（オープンループ版で78%ゼロだった結果のMPC版）

### 4. 実機ノード化（〜7/15）

- `rover/mpc_follower.py`（L2/L1をパラメータで切替、follower_coreの
  経路射影・誤差計算を流用、入出力はpath_followerと同一）
- 実機で短い経路を走らせて動作確認、求解時間の実測ログ取得

### 完了条件（M1）

- simでKanayama/L2/L1の3者が同条件比較できる
- 実機でL2/L1-MPCノードが制御周期内に動き、経路を完走する

## P2: 3者比較実験フェーズ（7/15〜8/31）

### 1. 評価パイプライン（〜7月末）

- rosbag解析スクリプト: bagから4指標（RMSE/Σ|u|/ゼロ入力率/求解時間）を
  自動算出（uvでrosbagsパッケージ、ラップトップで実行）
- sim結果と実機bagを同じ指標で出せるようにする（YAML設定→results/自動保存）

### 2. 本実験（〜8月末）

- 経路3種（直線・L字・圃場模擬の往復+180°旋回）× 3制御器 × 複数回走行
- λスイープの実機版（代表3点程度）
- 必要に応じCasADi+IPOPT（非線形MPC）を試し、cvxpy線形MPCとの差を評価
  （重ければ「RPi実装はQPが現実解」という結論自体が知見）

### 完了条件（M2）

- 「L1はL2比でゼロ入力率X%、エネルギーY%減、RMSE Z cm悪化、求解時間W ms」
  と実機データで言える

## リスクと対策

| リスク | 対策 |
|--------|------|
| RPi4でMPCが周期内に解けない | P1冒頭のベンチで早期判定。縮退: 周期0.2s/N短縮/低電圧監視 |
| 電源の低電圧でクロックダウン→計測汚染 | hwmonアラーム併記をベンチ手順に組込み（handoff参照） |
| L1のλ調整が発散 | simでスイープしてから実機へ。λ=0でL2に退化するので連続的に探索可 |
| 実機データのやり直し | rosbag生データ主義（指標は後から再計算可能） |
| 旋回スリップの床材依存 | 実験場所を固定し、場所ごとにスピン較正（spin_test.py）してから走行 |
